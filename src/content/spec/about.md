# 关于

这里是「氡」的记录空间，用来存放一些技术笔记和踩坑记录。

## 关于本站

- 使用 [Astro](https://astro.build/) + [Fuwari](https://github.com/saicaca/fuwari) 构建
- 文章以 Markdown 撰写，托管在 Cloudflare Workers
- 全站静态渲染，支持全文搜索、标签与分类归档
